# Agents SKILLS
Les agents IA et les outils couvrant l'ensemble du cycle de vie des tests logiciels : analyse des exigences, planification des tests, conception des tests, exécution, gestion des anomalies, clôture.

Ce dépôt contient des compétences d'agent réutilisables, c'est-à-dire des ensembles d'instructions autonomes qui guident les agents de codage IA (Gemini, etc.) afin qu'ils réalisent des tâches spécialisées de QA et de tests.
